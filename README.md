## 🏛️ About the Project

**CAFE 1991** is a production-grade restaurant web platform designed with high-end editorial aesthetics (*warm ivory, cream, terracotta, sage*), real culinary photography, authentic dishes from Tashkent, and interactive 3D WebGL experiences.

* **Address**: Mustaqillik shoh ko‘chasi, 7, Tashkent, Uzbekistan
* **Phone**: `+998 90 919 91 00` / `+998 71 200 91 00`
* **Cuisine**: Modern Uzbek, Lebanese & Middle Eastern Fusion

---

## ✨ Features

- 🍲 **Complete Authentic Menu**: 138+ real dishes with prices, descriptions, and local high-res photos.
- 🎨 **Editorial Soft Luxury Palette**: Bespoke styling with zero generic black+gold tropes.
- 🧊 **3D Interactive Visuals**: WebGL pure Three.js hero platter and 360° dish inspection.
- 📅 **Multi-step Reservation Wizard**: Validated booking flow with concept ticket passes.
- 📖 **Gastronomic Journal**: Curated articles on Tashkent heritage, ceramics, and tea culture.
- 🖼️ **Interactive Gallery**: Filterable photo gallery with full-screen lightbox modal.
- 🚀 **Next.js 15 & React 19**: Blazing fast SSG + SSR, fully responsive, zero TypeScript errors.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Styling**: [React 19](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: [Three.js](https://threejs.org/) (WebGL Canvas)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/), [Zod](https://zod.dev/)

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/lobaroy35-maker/cafe-1991.git

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
npm run start
```
